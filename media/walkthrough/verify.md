# Verify it's working

**Verify Setup** runs a quick health check: it confirms the hook script is installed, registered in your Claude settings, and actually captures an edit end-to-end.

If anything's off, it tells you exactly what to fix (usually: re-run Setup Hook, or restart a Claude session so it reloads the hook).

You can re-run this anytime from the **Settings** panel in the Claude Gate sidebar.
